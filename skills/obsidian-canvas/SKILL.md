# Obsidian canvas

## 1. Block size: no scrolling

A block is at least as tall as its rendered text. Estimates at zoom 1:

| Part | Size |
|---|---|
| `##` heading line | 48 px |
| Body line | 26 px |
| Content padding | 28 px vertical, 48 px horizontal |
| Body glyph | 8.4 px, inline code 9.4 px, heading 13.5 px |

A line wider than the block wraps and counts as several lines. Entity blocks
share one width per diagram (300 px is a good default). A label block is as
wide as its longest line plus the padding, with no extra margin.

## 2. Text formatting

- Inline code for literal names: fields, tables, enum values, permissions,
  cardinality such as `` `1 - *` ``.
- A code block only for real multi-line code or config.
- Descriptions stay plain text. One fact per line; short lines.

## 3. Lines run through empty space

- A line never passes over, under or along a block other than the two it
  connects, and keeps at least 12 px of clearance from every other block.
- Group borders are not blocks: lines may cross them. A block is either fully
  inside a group or fully outside it.
- Lines do not cross other lines where a different layout avoids it.

## 4. Straight lines, text in blocks

Obsidian draws a line from the middle of one block side to the middle of the
other. The line is straight only when the two sides face each other and line
up: right to left at the same center `y`, or bottom to top at the same center `x`.

- **Grid**: blocks in one row share one center `y`; in one column, one center `x`.
- **Turns**: a line turns through an empty 10 x 10 text block at the corner.
- **Labels**: a line never has a `label`. The text goes into a small label block
  placed on the line, which splits it into two collinear segments.
- **Branches**: a block with more relations than free sides gets one line to a
  branch block (empty 10 x 10, or a shared label block), and branches start there.
- **Arrows**: only the last segment of a relation has an arrowhead; segments
  ending in a turn, label or branch block have `"toEnd": "none"`.

## 5. Spacing

- Column gap: the widest label block in that gap plus 24 px on each side, at
  least 100 px.
- Row gap 110 px; between groups 200 px; group padding 40 px.

## Building and checking

A canvas with more than a few blocks is generated by a scratch script (entities
on grid cells, rows sized by their tallest block, label and turn blocks computed
from the grid), not placed by hand. The script stays out of the knowledge base.

Before finishing, the checker reports 0 problems:
```
py <this skill's folder>/canvas-check.py <file.canvas>
```
It checks rules 1, 3 and 4. Its size estimates are approximate: a block that
still scrolls in Obsidian means the constants need adjusting.
